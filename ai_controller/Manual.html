AI Controller Plugin for Krita

This plugin exposes a local HTTP bridge (default port 5678) allowing AI assistants and external scripts to control Krita programmatically.

Features

  • Thread-safe main thread dispatch via Qt QTimer
  • Canvas inspection and rendered PNG snapshots
  • Document & layer management (paint and vector layers)
  • Brush presets, size, opacity, and color controls
  • Real-time stroke, line, shape, and pixel painting
  • SVG path insertion on vector layers
  • Live Docker panel with activity log and status control
